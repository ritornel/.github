# .github

The Ritornel organisation's profile on GitHub. `profile/README.md` is what [github.com/ritornel](https://github.com/ritornel) shows at the top of its page.

The banners in `profile/` are drawn in the website's repository, `ritornel/website`, by `scripts/brand.py`, from the site's own words, pictures and colours, and copied here when this repository is checked out beside it. Change them there and commit the copies here; never edit them by hand. The banners link by their full address on `main`, so they show once a change is merged.
